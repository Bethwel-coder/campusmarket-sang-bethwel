# CampusMarket — Web Based Programming II

CampusMarket is a database-driven e-commerce platform designed for a university community.

## Weeks 1–4 Features
- **Semantic HTML5 & Responsive CSS3**: Fully structured layouts across home, catalog, and registration pages.
- **Dynamic Product Search & Filtering**: Client-side filtering by query string and category selection.
- **Integrated Product Gallery**: Gallery slideshow automatically updates based on active search/category filters.
- **Validated Subtotal Calculation**: Running order total updates strictly against validated quantity values.
- **Interactive Registration Form**: JS client-side validation with smooth CSS transitions for errors and dynamic success animation overlays.
